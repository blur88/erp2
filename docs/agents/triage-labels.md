# Triage Labels

The triage skills use category labels and five canonical state labels. This file maps them to the labels used in this repo's GitHub issue tracker.

| Role | Label in our tracker | Meaning |
| --- | --- | --- |
| `bug` | `bug` | Something is broken |
| `enhancement` | `enhancement` | A feature or improvement |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a category or state role, use its mapped label. Edit the label column if the tracker vocabulary changes.
