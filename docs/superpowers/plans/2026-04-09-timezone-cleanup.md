# Timezone Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove hardcoded `Asia/Kuala_Lumpur` from Docker, database config, and analytics date-range resolvers so the user's configured timezone from `RegionalSettings` is respected end-to-end.

**Architecture:** Docker containers and PostgreSQL run UTC. A shared `resolveDateRange` utility (using `luxon`) computes date-range boundaries in the user's configured timezone. Three analytics services (inventory, purchasing, sales) delegate to the shared utility instead of computing boundaries locally with `new Date()`.

**Tech Stack:** NestJS 11, TypeORM, PostgreSQL, `luxon` (already in `backend/node_modules`), Jest

### Task 5: Implement the shared date-range utility

```ts
import { DateTime } from 'luxon';
import { DateRange } from '@/common/dto/analytics.dto';

export function resolveDateRange(
  timezone: string,
  dateRange?: DateRange,
  customStartDate?: Date,
  customEndDate?: Date,
  now: Date = new Date(),
): { startDate: Date; endDate: Date } {
  if (customStartDate && customEndDate) {
    const normalizedStart = new Date(customStartDate);
    normalizedStart.setUTCHours(0, 0, 0, 0);
    const normalizedEnd = new Date(customEndDate);
    normalizedEnd.setUTCHours(23, 59, 59, 999);
    return { startDate: normalizedStart, endDate: normalizedEnd };
  }

  const dt = DateTime.fromJSDate(now, { zone: timezone });
  const endOfToday = dt.endOf('day');

  let startDate: Date;
  let endDate: Date = endOfToday.toJSDate();

  switch (dateRange) {
    case DateRange.TODAY:
      startDate = dt.startOf('day').toJSDate();
      break;

    case DateRange.THIS_WEEK:
      // Luxon week starts Monday by default; we want Sunday (JS convention)
      startDate = dt.startOf('day').minus({ days: dt.weekday % 7 }).toJSDate();
      break;

    case DateRange.THIS_MONTH:
      startDate = dt.startOf('month').toJSDate();
      break;

    case DateRange.THIS_QUARTER: {
      const quarterStart = Math.floor((dt.month - 1) / 3) * 3 + 1;
      startDate = dt.set({ month: quarterStart }).startOf('month').toJSDate();
      break;
    }

    case DateRange.THIS_YEAR:
      startDate = dt.startOf('year').toJSDate();
      break;

    case DateRange.LAST_WEEK: {
      const dayOfWeek = dt.weekday % 7; // 0=Sun, 6=Sat
      const startOfThisWeek = dt.startOf('day').minus({ days: dayOfWeek });
      startDate = startOfThisWeek.minus({ weeks: 1 }).toJSDate();
      endDate = startOfThisWeek.minus({ milliseconds: 1 }).toJSDate();
      break;
    }

    case DateRange.LAST_MONTH: {
      const lastMonth = dt.minus({ months: 1 });
      startDate = lastMonth.startOf('month').toJSDate();
      endDate = lastMonth.endOf('month').toJSDate();
      break;
    }

    case DateRange.LAST_QUARTER: {
      const currentQuarterStart = Math.floor((dt.month - 1) / 3) * 3 + 1;
      const lastQuarterStartMonth = currentQuarterStart - 3;
      const lastQuarterDt = lastQuarterStartMonth < 1
        ? dt.set({ year: dt.year - 1, month: lastQuarterStartMonth + 12 })
        : dt.set({ month: lastQuarterStartMonth });
      startDate = lastQuarterDt.startOf('month').toJSDate();
      endDate = lastQuarterDt.plus({ months: 2 }).endOf('month').toJSDate();
      break;
    }

    case DateRange.LAST_YEAR: {
      const lastYear = dt.minus({ years: 1 });
      startDate = lastYear.startOf('year').toJSDate();
      endDate = lastYear.endOf('year').toJSDate();
      break;
    }

    default: // THIS_MONTH
      startDate = dt.startOf('month').toJSDate();
      break;
  }

  return { startDate, endDate };
}
```
