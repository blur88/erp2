# AJV Update to 8.18.0 — Design

**Date**: 2026-03-04
**Scope**: Backend only

## Summary

Update the transitive AJV dependency in the backend from `8.17.1` to `8.18.0` by pinning it via npm `overrides`.

## Context

AJV is not a direct dependency of the backend application code. It is pulled in transitively by:
- `@angular-devkit/core`
- `@nestjs/cli` / `@nestjs/schematics`
- `webpack`, `terser-webpack-plugin`, `schema-utils`

All consumers already require `^8.x`, so bumping from `8.17.1` → `8.18.0` is a compatible minor update.

AJV `8.18.0` was released 2026-02-14 and is currently the `latest` tag on npm.

## Approach

Add `"ajv": "8.18.0"` to the `overrides` block in `backend/package.json`. This is consistent with the project's existing override pattern (glob, body-parser, tar, js-yaml, qs).

## Changes

- `backend/package.json`: add `"ajv": "8.18.0"` to `overrides`
- `backend/package-lock.json`: regenerated by `npm install`

## Verification

After install, `backend/node_modules/ajv/package.json` should show version `8.18.0`.
