# ESLint 9 + eslint-plugin-react-refresh 0.5.2 Upgrade Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Upgrade `eslint-plugin-react-refresh` from 0.4.5 to 0.5.2, which requires upgrading ESLint from 8 to 9 and migrating the config from legacy `.eslintrc.cjs` to flat `eslint.config.js`.

**Architecture:** ESLint 9 drops support for `.eslintrc.*` legacy config and requires flat config (`eslint.config.js`). The plugin `eslint-plugin-react-refresh@0.5.x` ships as ESM and only supports ESLint 9. `@typescript-eslint` must be upgraded from v6 to v8 for ESLint 9 compatibility. All currently-disabled rules stay disabled — linting behaviour is unchanged.

**Tech Stack:** ESLint 9, typescript-eslint v8, eslint-plugin-react-hooks v5, eslint-plugin-react-refresh v0.5.2, Node 20, Vite 7 project (frontend only)

### Task 2: Create the flat ESLint config

**Files:**
- Create: `frontend/eslint.config.js`
- Delete: `frontend/.eslintrc.cjs`

**Step 1: Create `frontend/eslint.config.js`**

```js
import js from '@eslint/js';
import tseslint from 'typescript-eslint';
import reactHooks from 'eslint-plugin-react-hooks';
import { reactRefresh } from 'eslint-plugin-react-refresh';

export default tseslint.config(
  { ignores: ['dist'] },
  js.configs.recommended,
  ...tseslint.configs.recommended,
  {
    plugins: {
      'react-hooks': reactHooks,
      'react-refresh': reactRefresh.plugin,
    },
    rules: {
      // react-hooks
      ...reactHooks.configs.recommended.rules,
      'react-hooks/exhaustive-deps': 'off',
      'react-hooks/rules-of-hooks': 'off',

      // react-refresh
      'react-refresh/only-export-components': 'off',

      // typescript-eslint — keep current permissive settings
      '@typescript-eslint/no-unused-vars': 'off',
      '@typescript-eslint/no-explicit-any': 'off',
      '@typescript-eslint/ban-ts-comment': 'off',
      '@typescript-eslint/no-empty-object-type': 'off',
      '@typescript-eslint/no-require-imports': 'off',
      '@typescript-eslint/ban-types': 'off',

      // base ESLint
      'no-unused-vars': 'off',
      'no-extra-semi': 'off',
      'no-extra-boolean-cast': 'off',
      'prefer-const': 'off',
      'no-useless-escape': 'off',
      'no-case-declarations': 'off',
      'deprecation/deprecation': 'off',
    },
  },
  {
    files: ['**/*.ts', '**/*.tsx'],
  },
);
```

Note: `deprecation/deprecation` was in the old config but the `deprecation` plugin was never listed in the packages — it was dead config. Leaving it as `'off'` is harmless. If ESLint throws "unknown rule" for it, remove that line.

### Task 3: Update the lint script

**Files:**
- Modify: `frontend/package.json`

**Step 1: Check current lint script**

In `frontend/package.json`, the lint script is:
```json
"lint": "eslint . --ext ts,tsx --max-warnings 0"
```

In ESLint 9 flat config, file extension filtering is done via the `files` glob in the config, not `--ext`. The `--ext` flag is ignored (or throws a warning) in ESLint 9. Update the script to remove it:

```json
"lint": "eslint . --max-warnings 0"
```

**Step 2: Apply the edit to `frontend/package.json`**

Find the line:

## Troubleshooting

**`eslint-plugin-react-hooks` import issue:** If `reactHooks.configs.recommended.rules` is undefined in v5, try:
```js
import reactHooks from 'eslint-plugin-react-hooks';
// use: reactHooks.configs['recommended-latest'].rules
// or:  ...reactHooks.configs.recommended.rules
```
Check the plugin's README for the exact flat config export name.

**`eslint-plugin-react-refresh` import issue:** The named export is `reactRefresh` from `'eslint-plugin-react-refresh'`. If the import fails, try the default import:
```js
import reactRefreshPlugin from 'eslint-plugin-react-refresh';
// use: reactRefreshPlugin.plugin  (or just reactRefreshPlugin directly as the plugin object)
```

**ESLint can't find `typescript-eslint`:** Make sure the package name is exactly `typescript-eslint` (not `@typescript-eslint/typescript-eslint`). Confirm with `npm ls typescript-eslint`.
